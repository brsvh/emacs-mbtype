*** 日本語 — かな・カタカナ・漢字

ひらがな：あいうえお、かきくけこ、さしすせそ。
カタカナ：アイウエオ、カキクケコ、サシスセソ。
小書き：ぁぃぅぇぉっゃゅょ、ァィゥェォッャュョ。

**** 한국어 — 받침・한자・mixed text

받침：각 간 갇 갈 감 갑 값 갓 강；읽다、앉다、없다。

한자：韓國、文字、圖書館、學校；한글과 漢字를 함께 읽기。

All three rows contain the same Han code points.  A frame-wide priority
normally gives them the same font; the labels do not request local variants.
Compare these rows after changing the actual font configuration.

Different code points: =高 / 髙=, =崎 / 﨑=, =吉 / 𠮷=.

These are coverage samples, not a promise that every font supports them.

#+name: multilingual-label
#+begin_src emacs-lisp
(let ((書名 "雨の日の図書室")
      (作者 "佐藤葵")
      (쪽수 144))
  ;; 中文注释、日本語の注釈、한국어 주석。
  (format "%s — %s (%d pp.)" 作者 書名 쪽수))
#+end_src

#+begin_src python
def label(書名: str, 作者: str, 쪽수: int) -> str:
    """Keep 中文、日本語、한국어 and Latin text together."""
    if 쪽수 < 0:
        raise ValueError("页数 / ページ数 / 쪽수")
    return f"{作者} — {書名}: {쪽수}"
#+end_src
